\# E-commerce Analytics and ML Project



\## Цель проекта



Проанализировать данные e-commerce заказов и построить модель, которая предсказывает вероятность плохого отзыва клиента.



\## План проекта



1\. Загрузка и описание данных

2\. Очистка данных

3\. Исследовательский анализ

4\. SQL-анализ

5\. Создание признаков

6\. Обучение ML-моделей

7\. Анализ результатов

8\. Бизнес-выводы



\## Стек



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- SQL

\- Scikit-learn
